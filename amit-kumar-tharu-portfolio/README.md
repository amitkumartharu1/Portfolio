## Run locally

Open `index.html` directly, or use:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy free on Vercel

This is a static site and requires no build command. Vercel's current Hobby plan is free for personal/non-commercial use. You can deploy the folder or ZIP with Vercel Drop, or connect a GitHub repository for automatic deployments.

### Fastest method — Vercel Drop

1. Open https://vercel.com/drop
2. Drag the extracted portfolio folder or ZIP into the page.
3. Sign in to Vercel if requested.
4. Choose a project name, for example `amit-kumar-tharu-portfolio`.
5. Click **Deploy**.
6. Vercel will provide a live `.vercel.app` URL.

### GitHub + Vercel method

1. Create a GitHub repository named `amit-kumar-tharu-portfolio`.
2. Upload all files from this folder, keeping `index.html` at the repository root.
3. In Vercel, choose **Add New → Project** and import the GitHub repository.
4. Leave the framework/build settings as the static defaults; there is no build command or output directory required.
5. Deploy. Future GitHub pushes can then trigger Vercel deployments.

Important: Vercel's Hobby plan is currently intended for personal/non-commercial use.
